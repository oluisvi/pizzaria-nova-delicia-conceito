# Pizzaria Nova Delícia — prévia digital

Vitrine demonstrativa mobile-first para a Pizzaria Nova Delícia, em Jacareí. Os dados e fotos vêm do perfil público oficial e do cardápio enviado em conversa de WhatsApp.

## Abrir
- Site: `index.html`
- Prancha responsiva: `arte/prancha.html`
- PNG para apresentação: `arte/pizzaria-nova-delicia-prancha.png`

## Conteúdo e limites
- Inclui uma seleção de 18 sabores do material recebido, busca, filtro e lista de consulta via WhatsApp.
- Os preços exibidos são referências das páginas enviadas e precisam ser confirmados antes de uso. Ingredientes, tamanhos, disponibilidade, combos e horários também devem ser validados pela equipe.
- A interação abre o WhatsApp com uma consulta pré-preenchida; não registra pedidos ou pagamentos.
- Fotos são arquivos de imagem do perfil oficial, sem embed ou controles de vídeo. Confirmar autorização de uso para publicação definitiva.
